Useful Excel VBA Macro: Auto Consolidation

Daily shift reports aur coal weights log sheets ko consolidated file master database sheet me compile karne ke liye macro code:

VBA Macro - CopyDataToMaster() 
Sub CopyDataToMaster()
    Dim wsSource As Worksheet
    Dim wsDest As Worksheet
    Dim nextRow As Long
    
    ' Define sheets (Update names as per your workbook)
    Set wsSource = ThisWorkbook.Sheets("Daily_Shift_Report")
    Set wsDest = ThisWorkbook.Sheets("Master_Consolidated")
    
    ' Find next empty row in master sheet (column A)
    nextRow = wsDest.Cells(wsDest.Rows.Count, "A").End(xlUp).Row + 1
    
    ' Copy data (Assuming headers are same, range A2:E50)
    wsSource.Range("A2:E50").Copy
    
    ' Paste special values only to avoid breaking cell styles
    wsDest.Range("A" & nextRow).PasteSpecial Paste:=xlPasteValues
    
    ' Clear clipboard selection
    Application.CutCopyMode = False
    
    ' Show Hinglish alert for reassurance
    MsgBox "Data successfully backup ho gaya master sheet me!", vbInformation, "Operations Master Sync"
End Sub
